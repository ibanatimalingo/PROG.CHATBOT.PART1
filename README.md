Programming 1 POE Part 1 Registration and Login System

About This Project
This is Part 1 of my Portfolio of Evidence project for Programming 1, built in Java. It is a user registration and login system. I made this as part of my first year studies in IT Business Systems at Rosebank College IIE.

What It Does
Registers a new user and checks the username, password, and cellphone number
Logs a registered user in and out
Includes tests that check the login and registration logic works correctly

Tech Stack
Java
JUnit for testing

Project Structure
Main.java is the entry point and menu logic
Login.java has the registration and login logic
LoginTest.java has the unit tests.

Status
Part 1 is complete

Learning Notes
This project shows where I am at with Java as a first year student. It covers basic ideas like checking user input, organizing code into classes, and writing tests.
