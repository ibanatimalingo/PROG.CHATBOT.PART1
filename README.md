Programming 1 POE QuickChat Messaging System

About This Project
This is my completed Portfolio of Evidence project for Programming 1, built in Java. It is a console-based user registration, login, and messaging application. I made this as part of my first year studies in IT Business Systems at Rosebank College IIE.

What It Does
Registers a new user and checks the username, password, and cellphone number
Logs a registered user into the QuickChat console menu
Creates and sends messages with length checks, random 10-digit message IDs, and message hashes
Stores messages to a local JSON file and loads them into arrays for reporting
Searches messages by ID or recipient, finds the longest message, and deletes messages by hash
Includes unit tests that check the login, registration, and message array logic works correctly

Tech Stack
Java
JUnit for testing
JSON for local message storage
GitHub Actions for automated testing

Project Structure
Main.java is the entry point and handles the console menus
Login.java has the registration and login logic
Message.java handles message validation, ID and hash creation, and saving to JSON
MessageManager.java loads stored messages into arrays and handles searching, deleting, and reports
LoginTest.java has the unit tests for registration and login
ManagerTest.java has the unit tests for message arrays and reporting

Status
Parts 1, 2, and 3 are complete

Learning Notes
This project shows where I am at with Java as a first year student. It covers checking user input with regular expressions, organizing code into separate classes, working with arrays and JSON files, and writing unit tests.
